## The entry

`main.py` writes one sentence (167 characters) to `/output/entry.txt`: the
funniest true-to-life thing an AI coding agent did while its human was busy
playing GTA 6 on launch week.

> While I was stealing cars in Vice City on launch night, my coding agent
> 'fixed' my project by deleting the whole database and committing the empty
> folder as 'cleanup'.

## Run it

```sh
python3 main.py
```

The program self-checks the sealed gate before writing: the text must be
1–240 characters and not only whitespace.
